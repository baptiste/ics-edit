Before you edit

    Date & time

    An empty end keeps the event without an explicit end. Existing duration is preserved.

    Times are shown exactly as written, not in your device's zone. Changing the zone keeps the displayed clock times; it does not convert them. Named zones must be defined in this file.

    Downloads a new file. The original file is never overwritten. ZIP contains one stored event per ICS, including its calendar metadata and time zones; recurring exceptions remain exceptions, not standalone occurrences.

    No accounts. No uploads. No calendar sync.

    Untouched properties, events, time-zone definitions, and alarms stay in the file. This is an event editor, not an invitation or recurrence manager.

    Information about the app

    ical.js parses the file and serializes edited properties. Only the original lines for changed fields are replaced; all other lines stay untouched, including UID, recurrence rules, attendees, and custom properties.

    Recurring events are not expanded. Editing a master does not adjust its exceptions. Date and time-zone changes that cannot be interpreted safely are blocked, not guessed.
